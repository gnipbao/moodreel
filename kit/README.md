# kit：影片代码的原语库

按时间绘制的页面（`window.render(t)`）用的 ES 模块，无依赖、全确定性：同一个 t 永远画出同一帧，可以任意顺序、
多进程渲染。`moodreel kit <项目>` 会把这些文件连同风格专属的 `tokens.js`、`motion.js` 复制进项目；影片目录再
复制一份，保持自包含。

| 模块 | 内容 |
|---|---|
| `stage.js` | 页面契约：`stage({ width, height, duration, fonts, faces, images, prepare, draw, finish })` 设置 `DUR`/`render`/`READY`，按设计尺寸绘制，任意输出尺寸自动缩放；`faces` 按字族名注册字体文件，`prepare` 在字体和图片就绪后、第一帧之前跑一次（要量字的东西在这里建）；`texts(fn)` 提供文字停留检查用的 `TEXTS`。运动模糊：渲染器 `--samples N --shutter s` 时，每帧是快门内 N 个子帧的平均，`draw` 每个子帧画一次，`finish(g, t, src)` 在平均好的画面上跑一次（颗粒、暗角、闪光） |
| `music.js` | 跟着歌走：`music(AUDIO, LYRICS)` 读 `moodreel music` 写的 `music-data.js`，给出 `hit`（鼓点冲击）、`env`（包络）、`beatAt`/`barAt`、`ct`（踩拍的镜头时钟）、`step`、`sung`/`letters`/`span`（词在什么时候真正被唱出）、`slams`（砸字）；`pop`（字落下）。做法和数值见 docs/MUSIC-SYNC.md |
| `gl.js` | GPU 层：`gpu(w, h)` 给出全屏着色器 pass（`pass`，HDR 半浮点目标 `rt`，多输出 G-buffer）、Canvas 图层当纹理（`layer`）、每帧成千上万根抗锯齿发丝线（`lines`，2D 像素或带相机的 3D）、混合模式合成（`comp`）和胶片后期（`post`：辉光金字塔、晕光、色差、色调肩部或 `agx: 1` 换成 Blender 的 AgX 色调曲线、饱和度、暗角、抖动和推近）；GLSL 库里有哈希、simplex 噪声、fbm、curl、2D/3D 距离场、平滑并集、版画排线和热度色阶。光线步进的生物、引力透镜、流线场都靠它。做法见 docs/GPU.md |
| `anim.js` | 按事件驱动的时间工具：`prog`（缓动进度）、`pulse`（命中后衰减）、`springStep`（弹簧阶跃）、`keys`（关键帧）、`frameIdx`（整帧不变的种子，抖动不在运动模糊里重影）、`hash`、`noise1`、`path`（按弧长走折线） |
| `outline.js` | 从 TrueType 文件读字形轮廓：`outline(buffer).charToGlyph(ch).getPath(x, y, size).commands`、`path2D`；简单和复合字形，cmap 4 和 12；用来把字拆成笔画、填粒子、让火花描字 |
| `eases.js` | GSAP 命名的缓动（与 `moodreel/motion/eases.py` 同一套公式，测试保证一致）和 `bezier(x1, y1, x2, y2)` |
| `core.js` | `tween`、`value`、`keys`（分段关键帧）、`stagger`、`step`（一拍二）、带种子的 `rng`、`hash`、`noise1` |
| `texture.js` | `paper`（纸底与斑驳）、`grain`（颗粒）、`vignette`（暗角）、`screen`（网点）、`scanlines`（扫描线）、`misregister`（套色错位）；收尾用的 `bloom`（光晕）、`halation`（高光周围的橙红晕）、`aberrate`（色差）。`grain` 和 `vignette` 的参数就是 `moodreel measure` 测出的数值，内部已按测量校准 |
| `text.js` | `fit`（按宽度定字号）、`wrap`（中英文换行）、`glyphs`（逐字位置，用于逐字动画） |
| `brush.js` | 绘画笔触：`stroke`（有宽度轮廓和毛边的笔触加鬃毛痕，`reveal` 控制画到哪里）、`wash`（水彩：多遍抖动叠加，边缘积色变深）、`dab`（刮刀：斜端、明暗抖动、受光起伏）、`crayon`（蜡笔：被纸纹打断的斑点）、`ink`（墨：芯加晕）、`repaint`（把用平涂画好的画面重画成刀块或笔触，沿边缘走，按画面颜色，缓存）；以及 `spine`、`ribbon`、`wobble`、`tooth` 几何工具。参数对应 `moodreel measure` 测出的 `TEXTURE.brush`（笔触边缘间距、方向、一致度） |
| `variant.js` | 批量变体：`pick(key, 默认值)` 读 film.json 里 `variants` 的参数（渲染器以 `window.VARIANT` 传进页面）；同一份画面代码，换调色板、种子、一句文案或片长，`moodreel film deliver --variant 名` 或 `--all-variants` 各出一条 |
| `media.js` | 真实素材：`const M = await load()`（在 stage 之前，全部帧载完页面才算就绪），`M.frame(name, t, { from, rate, loop })` 取影片时间 t 对应的那一帧（素材按影片帧率存成一帧一张图，任何一帧都能单独渲染，不需要视频寻址），`M.still(name)`、`M.data(name)`（CSV 解析成对象数组、JSON 解析好）、`M.credit(name)`（来源和许可，可直接上字幕卡）。素材由 `moodreel media add` 放进 `media/` 并写进 manifest 和 CREDITS |
| `three.js` | 3D：`layer3d(w, h, { background, shadows, exposure, fov, toneMapping })` 建 three.js 场景、相机和 WebGL 渲染器，`draw(g)` 把这一帧的 3D 画到舞台上（字和叠加层照常用 2D 画在上面），`look(eye, target)`、`orbit(angle, radius, height)`、`toScreen(point)`（把字钉在世界里的一点上）。每个物体、灯光和相机都由 t 算出，不用时钟和会保留状态的动画混合器。three.js（MIT）由 `moodreel film new` 为需要 3D 的风格复制到 `kit/vendor/three/`，并写进 CREDITS |
| `look3d.js` | 插画感 3D 的材质和原画时钟（配合 `three.js`）：`ramp({ lit, mid, shade, light, wrap, softness, terminator, termTint, formTint, stipple, boil, hold, side })` 返回一个色彩渐变材质，不读场景里的灯。表面按朝向 `light`（世界坐标里指向光源的方向，不必归一化）的程度取色：包裹后的漫反射 d = clamp((N·L + wrap) / (1 + wrap), 0, 1)，d = 0 处恰好是 `shade`，d = 1 处恰好是 `lit`，中段是 `mid`，三档在 gamma 2 的感知空间里混合，`softness` 是每档过渡的宽度（按 d 计）。上面再叠三样：交界线上的强调色 `termTint`（强度 `terminator`；不给颜色时由 `mid` 推出一个更饱和、偏玫红的颜色），背光一侧的形体阴影 `formTint`（`null` 关闭，最多盖住一半），以及点彩 `stipple`：格点固定在物体自己的静止姿势空间里，约一个输出像素大，蒙皮弯折、镜头移动时点都跟着表面走；每个点只把像素沿渐变推大约一档，所以点只出现在交界线和暗面，颜色都是渐变里本来就有的。`boil` 是每张新原画重画的点的比例，`hold` 是材质自己的两帧一换步长；`side` 是 three.js 的面向（默认 `THREE.FrontSide`；`THREE.DoubleSide` 时背面的法线翻过来，薄片两面着色都对）。配 `layer3d(…, { toneMapping: 'none' })`，屏幕像素就是设定的颜色（实测亮面 ΔE2000 0.33、暗面 0.00）；蒙皮网格和实例化网格直接可用，`material.clone()` 的副本仍读共享的帧号。`setFrame(n)` 设置所有 ramp 材质共用的帧号，点彩的重画按材质自己的 hold 在 n − n % hold 换；`frameOf(t, fps)` 是 t 时刻的帧号（`Math.floor(t * fps + 1e-4)`）；`held(t, fps, hold)` 是此刻屏幕上那张原画的时间：人物用 `held(t, 24, 2)` 两帧一换，镜头仍用 t；`guard(renderer)` 让编译或链接失败的着色器抛出 Error，消息里带编译日志和日志指向的源码行（three.js 默认只打日志、照常画黑），重复调用无害。另外导出 `THREE`。做法见 `skills/moodreel/references/produce/drawing.md` |
| `post3d.js` | 绘画感的后期链：`chain(renderer, opts)` 返回 `draw(scene, camera, frame)`，每帧调用一次：把场景渲进自己的半浮点渲染目标（带深度纹理；渲染器开了抗锯齿就用 4× MSAA），依次做各级后期，结果放到渲染器的画布上，再用 `g.drawImage(L.canvas, 0, 0, W, H)` 放上舞台（不要再调 `L.draw(g)`：它会不带后期重新渲染一遍）。各级按顺序：`ao`（从深度缓冲重建位置算两圈遮蔽，紧的一圈管接触，宽的一圈管腋下和地面，宽圈半径 `aoRadius`，世界单位，默认 0.6；遮蔽处乘以 `aoTint`，默认 `#4b3f66`，暗处偏紫而不是发灰）、`dof: { focus, aperture }`（薄透镜：focus 是对焦距离，世界单位；aperture 是无穷远处的模糊半径，占画面高度的百分比；邻点只有在自己的模糊够得着时才算进来，清楚的前景不会糊进柔和的背景）、`bloom`（六级金字塔，只取超过 `bloomThreshold` 的部分，默认 0.75，线性；泛光保持原色的饱和度）、`shoulder`（按最亮通道把高光压到 1 以内，色相不变，不发白）、`vignette`（角落压暗的比例），最后在编码后的画面上加 `grain`（按色调加权：中间调最强，暗部约三分之二，高光约六分之一；`grainSize` 是一颗跨几个像素）和 `mottle`（3–16 px 的气笔斑驳）。值为 0 就关掉那一级，全部关掉时等于直接渲染，逐像素相同。chain 自动调用 `look3d.guard(renderer)` 和 `look3d.setFrame(frame − frame % hold, true)`：点彩的重画（`boil` 那部分）、颗粒和斑驳都按 chain 的 `hold`（默认 1）换，材质自己的 hold 让位；`flicker` 比例的颗粒每帧都换；`fps`（默认 24）只记在选项里。输出跟渲染器的颜色空间一致，肩部是链里唯一的色调曲线（渲染器的 tone mapping 不再叠加）。导出的常量 `POST3D` 是全部默认值；`draw.opts` 就是正在用的选项，可以在帧之间改，给每个镜头单独调色（每帧都按 t 设好，因为任何一帧都可能单独渲染）；`draw.dispose()` 释放渲染目标和各级着色器。1080p 全部打开中位 7.7 ms/帧。另外导出 `THREE`。做法见 `skills/moodreel/references/produce/drawing.md` |
| `figure.js` | 读 `moodreel model build` 建好的角色：`<名>.json` 和旁边的 `<名>.bin`，只用 fetch 和类型化数组，不用 three.js 的附加模块。`const fig = await figure.load(url, { material })` 是异步的，放在 `stage({ prepare })` 里，然后 `L.scene.add(fig.root)`。`load` 返回一个 `Figure`：`root` 加载后是单位变换，模型坐标就是世界坐标（米，y 朝上，面朝 +z，左边在 +x）；`bones` 是 `{ 骨骼名: THREE.Bone }`，静止时只有位置、不带旋转，所以每根骨骼的坐标轴起初都与世界平行；`meshes` 是每个部件一个 `SkinnedMesh`，`name` 是部件名，共用一副 `skeleton`；还有 `vertexCount`、`poses`、`expressions`、`landmarks`（静止姿势下的命名点：架镜头、钉字、量比例）和 `materials`（规格里的 MATERIALS 原样照搬，比如每种材质名的 ramp 参数）。每帧按这个顺序调用：先 `setPose(pose)`（姿势名，或 `{ 骨骼名: [rx, ry, rz] }`：度，XYZ 欧拉角，绕骨骼的静止坐标轴；没写到的骨骼回到静止）和 `setExpression({ 表情名: 权重 })`（按权重叠加规格里 EXPRESSIONS 的转角，没定义的忽略），这两个每次都重设全部骨骼；再 `reach(side, target, pole)`（双骨骼 IK：转动 `<side>_upperarm` 和 `<side>_forearm`，让 `<side>_hand` 的原点落到 target 上，target 是 `[x, y, z]` 或 Vector3；肘保持铰链、前臂不扭，够不着就伸直指向目标；`pole` 是肘部朝向的世界点，默认在肩的后下外侧）和 `aimHead(point, weight)`（头转向一点，转 weight 那么多，颈部先分担约三分之一）。`attach(object, bone, at)` 把道具挂到骨骼上（`at` 是它在静止姿势下所在的世界坐标点，比如手里的笔）。材质默认每种材质名一个哑光的 standard 材质；`load(url, { material })` 和 `fig.setMaterial(material)` 都接受一个函数 `(部件名, 材质名) => THREE.Material`、一个所有部件共用的材质，或按部件名或材质名索引的对象（没给到的用默认）。`moodreel.model3d.skin` 在 Python 里做同样的运算（`moodreel model check` 用它量穿插）；figure.js 在浏览器里摆出的顶点与它逐个比对，最大差 4.4e-16 m。做法见 `skills/moodreel/references/produce/drawing.md` |
| `3dcv/` | 从 [3DCodeVerse](https://github.com/gaoypeng/3dcodeverse) 的 [awesome showcase](https://huggingface.co/datasets/3dcodeverse/3dcodeverse-awesome-showcase) 移植来的画面引擎（展示片 r02 轮的通用代码），建在 `three.js` 上，和 `look3d.js`、`post3d.js` 是两套：材质跟着场景里的第一盏平行光走（主光要接近白色），后期参数沿用展示片自己的结构，适合照展示片的做法出画面、直接用它调好的材质预设。入口是 `3dcv/stage.js` 的 `film({ width, height, ss, shots, extras, query })`：把镜头模块 `{ id, frames, hold, ss, init(ctx), render(ctx, n) }` 挂进 `stage()`（`prepare: () => film.init()`，`draw: (g, t) => film.draw(g, t, W, H)`），全片按 24 fps 数帧，`hold: 2` 两帧一换；所有镜头共用一个不放进页面的 WebGL 渲染器，画每一帧前先放回这个镜头的 init 留下的全局状态，所以每一帧都和之前画过什么无关；`render` 必须是同步的。其余模块：`look.js`（`preset`、`material`、`setEnv`、`skyDome`、`shadows`）、`post.js`（`Post`、`defaultPostParams`：超采样、SSAO、景深、辉光、镜头、按色调加权的颗粒）、`paint.js`（带种子的绘制纹理）、`text.js`（不用字体的笔画字）、`util.js`（`rng`、`track`、`spline`、`cameraRig` 等确定性工具）。许可的边界：这个目录是 CC BY-NC-SA 4.0，只能非商用，改编后仍按同一许可共享；kit 的其他文件是 MIT，不要把这里的代码复制或改写进去。`moodreel film new` 复制 kit 时它连同 `LICENSE` 一起进影片，准备商用的影片不能保留、也不能使用它。用法、ctx 和两帧一换见 `kit/3dcv/README.md`，逐文件的改动见 `kit/3dcv/LICENSE` |
| `lock.js` | 复刻的主体和镜头按参考片的画面对位：`lock(cam, TRACK, { set, moving }, { spans })` 读 `moodreel track --js` 写的 `track-data.js`（Jev 视觉在参考片每帧里框出的每个主体：`[t, seen, cx, cy, w, h]`），每个采样时刻做一次联合求解：镜头移动和转向（x、y、z、偏航、俯仰）加上可移动的主体沿允许的轴滑动（站在键盘上的小怪只在 x、z 上动，空中还能升降），让每个主体在画面里的可见部分（近裁剪面和画框都裁过）落在参考片的框里，Jev 没看到的主体推出画面；每一刻的解贴近上一刻（`hold`），镜头修正按 0.3 秒、主体按 0.2 秒高斯平滑（不给画面加参考片没有的运动），在片段两端淡入淡出（剪切点除外）。只靠框分不出镜像，加两个键位（空格、Esc）给出朝向。河、镇、人群这种不成一个凸体的主体写成 `{ cloud: points }`，取画面内那些点的外框。只锁布局已经和参考片一致的主体：布局不同时锁定只会让镜头停住（俯掠的运动掉到参考片的 0.31 倍）。`window.REPORT = () => L.report` 后 `node render/render.mjs report <影片>` 打印每个主体修正前后的像素误差。做法见 `skills/moodreel/references/distill/remaking.md` |
| `follow.js` | 复刻的镜头按参考片的走：`follow(MOTION, anchors, end, { own })` 读 `moodreel camera --js` 写的 `camera-data.js`（参考片每秒 15 次的画面平移、推拉、滚转），把测到的转向和推拉加在穿过几个锚点的平滑路径上：锚点处镜头站在、看向你定的位置，锚点之间按参考片的节奏摇、推。推拉沿当时的视线方向积分；滚转只听锚点（累加测到的滚转会漂）；`own` 里的时段（画面读的是主体而不是镜头，比如暗场里落下的碎块）锚点就是普通关键帧。锚点的 `speed` 定镜头经过它的快慢（0 即停，同 `ease`；1.5 冲过去），`speed: [进, 出]` 让进出不同：`[0.3, 1.7]` 是被跺脚震开的猛退，`[1.4, 0.2]` 是冲进去急停；`{ pace: true }` 让锚点之间的路径按参考片测到的速度走（参考片停它就等，参考片冲它就冲），每个运镜的形状（冲向揭示时加速、进入停顿时减速）直接来自参考片，`moodreel camera --against` 按三段速度核对。做法见 `skills/moodreel/references/distill/remaking.md` |
| `pixel.js` | 像素画：`pixels(w, h, palette)` 建一张低分辨率的索引帧（`put`、`rect`、`line`、`disc`、按 Bayer 抖动的 `shade`、字符画 `sprite`、一像素描边 `outline`），`present` 按整数倍、不插值放大画到舞台上，可传查找表；`reduce`（降色深表）、`stepTable`（沿色阶提亮或压暗）、`nearest`、`snap`（镜头按整像素移动）。参数就是 `moodreel measure` 测出的 `TEXTURE.pixel`（倍数、原生尺寸、色数、抖动） |

风格专属（由测量生成）：

| 文件 | 内容 |
|---|---|
| `tokens.js` | `SIZE`、`PALETTE`（ground / ink / accent / secondary 和全部颜色）、`TYPE`（标题和正文行高占画面比例、字重；字体族先占位，由导演选定有授权的字体）、`LAYOUT`（边距、对齐、密度）、`TEXTURE`（颗粒、斑驳、暗角、网点、扫描线、边缘） |
| `motion.js` | `MOTION`（入场 / 出场 / 位移的缓动、时长、cubic-bezier、过冲比例、起始缩放、位移幅度，错峰、静止、镜头长度、转场、一拍几、镜头运动），以及 `enter(t, at, i)`、`exit`、`move` 三个便捷函数 |

```js
import { stage } from './kit/stage.js';
import { PALETTE, TYPE } from './kit/tokens.js';
import { enter } from './kit/motion.js';

stage({ width: 1920, height: 1080, duration: 6, background: PALETTE.ground, draw: (g, t) => {
  g.globalAlpha = enter(t, 0.4);
```
